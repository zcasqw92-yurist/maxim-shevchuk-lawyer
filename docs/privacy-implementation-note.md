# Реализация модели прямого обращения

Дата: 27.07.2026.

## Принятое решение

Сайт не принимает обращения через собственные формы и не запрашивает контактные данные посетителя. Все действия «Написать», «Обсудить ситуацию» и «Узнать ориентир стоимости» ведут к единому выбору Telegram или WhatsApp.

Ссылка формирует заранее заполненный черновик. Черновик можно изменить, удалить или не отправлять. Оператор получает содержание только после самостоятельного действия пользователя во внешнем сервисе.

## Что удалено

- callback-форма и все её поля;
- имя, телефон, день, время и иные селекты;
- чекбокс согласия под формой;
- скрытое поле источника и textarea копии;
- квиз стоимости и локальное накопление его ответов;
- `FormData`, `reportValidity` и обработчики отправки формы;
- callback и quiz hooks из публикуемого HTML и клиентского JavaScript;
- связанные браузерные тесты и CSS.

## Что сохранено

- заранее заполненный текст прямого обращения;
- выбор Telegram или WhatsApp;
- тематический текст для страниц услуг и быстрых ситуаций;
- возможность изменить текст до отправки;
- аналитика по отдельному согласию — до будущего самостоятельного этапа её замены;
- политика конфиденциальности, описывающая фактические процессы после добровольной отправки.

## Контроль

`npm run test:direct-contact` должен подтверждать, что опубликованный HTML и клиентский JavaScript не содержат форм, полей ввода, callback или квиза, а прямые ссылки содержат предзаполненный черновик.

`npm run test:live` повторяет эту проверку после публикации.
