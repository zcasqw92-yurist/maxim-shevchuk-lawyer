# Контракт аналитики кнопок и действий

Дата: 30.07.2026.

## Цель

Каждая кнопка и каждый элемент, визуально выполняющий роль кнопки, должны передавать обезличенное событие `button_action` после согласия пользователя на аналитику.

Контракт распространяется на:

- все элементы `<button>`;
- ссылки с классом `.button` или `.text-link`;
- элементы с `role="button"`;
- кнопки открытия диалога `data-dialog-open`;
- прямые контакты `data-track`.

## Обязательные метки

Каждое событие `button_action` содержит:

- страницу, тип страницы и устройство;
- `button_id` — стабильный идентификатор действия;
- `button_label` — понятную метку кнопки;
- `button_kind` — тип действия;
- `button_placement` — смысловой блок размещения;
- `button_variant` — визуальный вариант;
- `button_destination` — только pathname внутренней ссылки либо домен/протокол внешнего назначения без query;
- заголовок ближайшего блока и юридическую тему страницы;
- тип и ID статьи, кейса или услуги;
- first-touch источник, посадочную страницу и обезличенный путь текущей вкладки.

## Конверсионные действия

`button_action` является диагностическим событием и не заменяет основные события:

- `cta_click` — нажатие CTA;
- `messenger_dialog_open` — открытие выбора мессенджера;
- `contact_conversion` — телефон, email, Telegram или WhatsApp;
- `contact_action` — карта и иные вспомогательные контакты.

Кнопка с `data-dialog-open` обязана дополнительно передать `cta_click`. Элемент с `data-track` обязан передать `cta_click` и соответствующее итоговое событие контакта.

## Приватность

В аналитику не передаются:

- текст подготовленного сообщения;
- содержание переписки и введённые пользователем сведения;
- значения `yclid`, `gclid`, `fbclid`;
- query-параметры назначения и внешнего реферера;
- конкретные ответы квиза.

Кнопки вариантов квиза передают нейтральную метку «Выбор варианта квиза», тип шага и необратимый технический идентификатор. Нажатие «Не разрешать» не отправляется во внешнюю аналитику.

## Правило для новых публикаций

Новая статья, кейс, услуга или иной шаблон не проходит `npm run check`, если:

- модуль `button-analytics.mjs` не подключён;
- хотя бы одна кнопка не формирует `button_action`;
- обязательная метка отсутствует;
- повторяется `button_id` в пределах страницы;
- контактная кнопка не формирует конверсионное событие;
- в параметры попадают сообщение, click ID, query либо ответ квиза.

Проверку выполняет:

```text
npm run test:button-analytics
```

Она автоматически строит список всех канонических страниц из данных услуг, статей и кейсов, поэтому новые публикации включаются в аудит без ручного обновления перечня URL.
