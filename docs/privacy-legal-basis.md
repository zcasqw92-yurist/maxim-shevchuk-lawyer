# Правовая модель сайта без контактных форм

Дата фиксации: 27.07.2026.

Этот файл описывает техническую и правовую логику реализации, но не заменяет индивидуальную юридическую оценку фактической работы оператора и исполнение обязанностей, которые возникают после получения сообщения.

## Разграничение процессов

1. Просмотр информационной страницы.
2. Техническая доставка страницы инфраструктурой хостинга и защиты.
3. Необязательная аналитика только после отдельного выбора посетителя.
4. Формирование браузером внешней ссылки с заранее заполненным черновиком.
5. Самостоятельное решение пользователя изменить, удалить либо отправить черновик.
6. Получение сообщения оператором только после отправки во внешнем сервисе.
7. Дальнейшая обработка для ответа, преддоговорных действий, заключения и исполнения соглашения, исполнения закона и защиты прав.

## Ограничения модели

Отсутствие форм уменьшает объём сбора через сайт, но не означает полного отсутствия обработки персональных данных оператором после добровольного обращения. Политика не должна содержать обещание правового иммунитета или утверждение, что мессенджеры не обрабатывают сведения.

## Технические гарантии

- опубликованный HTML не содержит `form`, `input`, `select` и `textarea`;
- клиентский JavaScript не содержит `FormData`, валидации или отправки веб-форм;
- отсутствуют callback и price quiz hooks;
- прямые ссылки содержат только заранее заданный черновик;
- содержание неотправленного черновика не поступает оператору;
- аналитика не получает содержание обращения;
- live-smoke повторно проверяет модель после публикации.
