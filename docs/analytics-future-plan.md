# Отложенный план аналитики без клиентских счётчиков

Решение от 27.07.2026: в текущем релизе аналитику не менять. Отдельным будущим этапом рассмотреть удаление кодов Яндекс Метрики и Google Analytics из клиентского HTML/JavaScript с сохранением статистики за счёт:

- Cloudflare Zone Analytics и технических edge-логов без внедрения браузерного beacon;
- Google Search Console для показов, кликов и запросов в Google;
- Яндекс Вебмастера для показов, кликов и запросов в Яндексе.

Не использовать как «скрытый обход» серверную отправку событий в Яндекс или Google, если фактически продолжается передача данных этим сервисам. Перед изменением необходимо отдельно сверить тариф Cloudflare, состав доступных отчётов, договорные документы и фактический набор обрабатываемых технических сведений.
