# Границы текущей реализации

Текущий релиз изменяет модель обращения и Политику, но не выполняет будущий переход аналитики на Cloudflare Zone Analytics.

Не затрагиваются:

- действующая схема отдельного согласия на аналитику;
- поисковые кабинеты;
- Cloudflare DNS и security headers;
- способы хранения материалов после фактического обращения вне сайта;
- обязанность оператора оценить уведомление Роскомнадзора и иные организационные меры.

Отсутствие формы на сайте не является гарантией отсутствия претензий и не отменяет обязанности после получения добровольного сообщения.
