# Аудит публикационных сессий

`latest.json` создаётся или обновляется при каждом изменении видимого контента сайта. Он подтверждает, что перед подготовкой были прочитаны актуальная Google-таблица и все её вкладки.

Правила:

- использовать структуру `template.json`;
- получать перечень вкладок динамически из текущих метаданных таблицы;
- перечислять все фактически обнаруженные вкладки, а не копировать базовый список вслепую;
- по каждой вкладке указывать фактически просмотренный используемый диапазон;
- не вставлять ФИО, телефоны, адреса, номера дел, полные реплики и иные персональные данные;
- использовать только внутренние ID источников и краткое описание их роли;
- обновлять manifest в том же наборе изменений, что и контент;
- фактические результаты CI, деплоя и live-тестов сообщать в итоговом отчёте в чате, чтобы не создавать циклический коммит после публикации.
