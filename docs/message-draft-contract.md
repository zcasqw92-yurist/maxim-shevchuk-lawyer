# Контракт предзаполненного сообщения

Базовый текст прямого обращения сохраняется без изменения:

> Здравствуйте, Максим Юрьевич. Хочу получить первичную оценку ситуации. Кратко опишу, что произошло, и приложу имеющиеся документы:

Для тематических CTA допускается подстановка названия выбранного вопроса или специального текста страницы услуги. Во всех случаях текст является редактируемым черновиком внешнего мессенджера и не передаётся оператору до самостоятельного нажатия пользователем кнопки отправки.
