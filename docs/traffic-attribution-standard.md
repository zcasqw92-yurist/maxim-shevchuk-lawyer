# Стандарт источников трафика и UTM-хвостов

Дата: 30.07.2026.
Версия: 1.0.

Этот документ является источником истины для всех ссылок на `https://yuristshevchuk.com/`, которые размещаются вне сайта. По запросу в чате «дай UTM-хвост» используется именно этот стандарт.

## 1. Что Метрика определяет автоматически

Яндекс Метрика самостоятельно определяет источник по рефереру и меткам первого просмотра визита. Сайт не подменяет эту атрибуцию, а дополнительно сохраняет обезличенный first-touch контекст и путь до обращения.

Автоматические параметры `yclid`, `gclid` и `fbclid` вручную не создаются и не копируются в пользовательские параметры. Сайт фиксирует только факт наличия соответствующего идентификатора.

## 2. Обязательные параметры управляемой ссылки

Каждая ссылка, которую размещаем самостоятельно, должна содержать:

- `utm_source` — конкретная площадка;
- `utm_medium` — тип канала;
- `utm_campaign` — постоянная тема или направление;
- `utm_content` — конкретное объявление, пост, карточка или место размещения.

`utm_term` используется только для платной рекламы и поисковой фразы. `utm_referrer` применяется только тогда, когда площадка не передаёт корректный реферер.

## 3. Правила написания

1. Только латиница в нижнем регистре.
2. Слова разделяются подчёркиванием.
3. Не использовать ФИО клиента, телефон, номер дела, сумму спора и содержание обращения.
4. `utm_campaign` не менять между объявлениями одной темы.
5. Конкретное размещение различать через `utm_content`.
6. Не использовать пробелы, кириллицу и случайные названия вроде `test1`.
7. Один и тот же источник всегда называется одинаково.

## 7. Готовые хвосты

### Авито, объявление по взысканию долга

```text
?utm_source=avito&utm_medium=classified&utm_campaign=vzyskanie_dolga&utm_content=ad_01
```

Следующее объявление той же темы:

```text
?utm_source=avito&utm_medium=classified&utm_campaign=vzyskanie_dolga&utm_content=ad_02
```

### Telegram, публикация в канале

```text
?utm_source=telegram&utm_medium=messenger&utm_campaign=vzyskanie_dolga&utm_content=channel_post_01

```

Автоматический `yclid` не добавляется вручную.

## 8. Как выбрать целевую страницу

UTM-хвост добавляется к наиболее точной посадочной странице:

- объявление про долг → страница услуги или соответствующий разбор о долге;
- пост про отказ полиции → соответствующая статья или услуга;
- общий профиль → главная или `/uslugi/`;
- публикация о конкретном кейсе → страница кейса.

Нельзя направлять все источники только на главную, если есть более точный материал.

## 9. Что передаёт сайт после согласия

В Яндекс Метрику передаются:

- первая посадочная страница;
- тип первой страницы;
- внешний домен и путь реферера без query-параметров;
- UTM-метки;
- только названия обнаруженных click ID, без их значений;
- последовательность внутренних страниц текущей вкладки;
- страница, материал, блок CTA и выбранный канал связи.

До согласия данные не отправляются во внешние аналитические системы. В текущей вкладке временно сохраняется только обезличенный first-touch контекст. При отказе он удаляется, а после закрытия вкладки `sessionStorage` очищается браузером.

## 10. Запросы в чате

Допустимые формулировки:

- «Дай хвост для объявления Авито по взысканию долга»;
- «Подготовь ссылку на статью для поста в Telegram»;
- «Сделай UTM для QR-кода на визитке»;
- «Дай три хвоста для разных объявлений одной кампании».

Ответ должен содержать готовый хвост и, когда указан URL, полную ссылку. Названия источников и каналов не придумываются заново, а берутся из этого документа.
