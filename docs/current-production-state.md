1. добавить страницу в генератор;
2. задать достоверную дату в `site.contentLastModifiedByPath`;
3. включить маршрут в структурный golden-контракт;
4. сохранить принудительный запрет индексации;
5. пройти полный `npm run check`.

## Индексация

Индексация намеренно закрыта по прямому указанию владельца и не является дефектом.

Финальный этап каждого деплоя:

- устанавливает на всех 14 HTML-файлах `noindex,nofollow,noarchive,nosnippet,noimageindex`;
- публикует пустой `sitemap.xml`;
- не рекламирует sitemap через `robots.txt`; запрет индексации HTML обеспечивается строгим meta robots на каждой странице;
- удаляет ключ IndexNow и не отправляет URL;
- записывает `indexingLocked: true` в `build-info.json`.

Эти правила распространяются также на все новые страницы и вкладки. Переменная `SITE_PRODUCTION=true` сама по себе не открывает индексацию: принудительный слой `npm run lock:indexing` выполняется после сборки. Снимать блокировку можно только по отдельной прямой команде владельца и отдельным изменением.

## Автоматические проверки

Основная команда:

```bash
npm run check
```

Она проверяет HTML, SEO-структуру, даты материалов, структурный golden-контракт, доступность, мобильную типографику, формы, диалоги, мессенджеры, страницы услуг, источники, производительность, Core Web Vitals, 12 визуальных разрешений и финальный indexing lock.

После деплоя обязательны:

```bash
SITE_PUBLIC_URL='https://zcasqw92-yurist.github.io/maxim-shevchuk-lawyer/' \
EXPECTED_BUILD_SHA='<полный commit SHA>' npm run test:live

SITE_PUBLIC_URL='https://zcasqw92-yurist.github.io/maxim-shevchuk-lawyer/' \
npm run test:live-indexing-lock
```

Чекбокс задачи ставится только после совпадения live SHA, прохождения публичных сценариев и повторной проверки запрета индексации.

## Release checklist

- [ ] Изменение изолировано и не включает сгенерированный `dist`.
- [ ] Для содержательной правки обновлена дата только затронутых страниц.
- [ ] При осознанном изменении структуры проверен diff `tests/golden-render-contract.json`.
- [ ] `npm run check` завершён без ошибок.
- [ ] Публикуемый tree совпадает с проверенным локальным tree.
- [ ] GitHub Pages отдаёт ожидаемый полный SHA.
- [ ] `npm run test:live` прошёл на публичном URL.
- [ ] `npm run test:live-indexing-lock` подтвердил блокировку.
- [ ] В рабочей Google Таблице записаны чекбокс, SHA, дата и результат.

## Что обновлять при смене домена или режима

До отдельного разрешения владельца этот раздел является только будущим чек-листом:

- подтвердить фактический домен, базовый путь и владельца домена;
- проверить canonical, редиректы, 404 и реальные HTTP-заголовки;
- завершить `LEGAL-01–04`, `LOCAL-01`, `TRUST-02` и решение по аналитике;
- отдельно согласовать открытие индексации;
- только после согласования пересобрать robots, sitemap, verification и IndexNow;
- повторно пройти полный технический, визуальный и юридико-контентный контроль.
