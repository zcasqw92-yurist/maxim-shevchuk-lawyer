# Инвариант no-form

После этого релиза публичная сборка не должна содержать формы передачи обращения или поля ввода контактных данных. Возврат таких элементов допускается только отдельным решением владельца с предварительным обновлением Политики, правовых оснований, согласий, хранения, безопасности и тестов.
