# Release note: прямое обращение без веб-форм

Планируемый релиз полностью убирает сбор контактных данных через интерфейс сайта. Пользователь выбирает Telegram или WhatsApp, получает предзаполненный черновик и самостоятельно отправляет его во внешнем сервисе.

Политика переработана под фактическую модель, включая инфраструктуру, аналитику по согласию, внешние сервисы, цели и основания обработки после обращения, специальные категории, сроки, права и меры защиты.
