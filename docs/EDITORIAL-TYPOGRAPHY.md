# Типографика редакционных страниц

Этот контракт применяется к `/razbory/`, `/praktika/`, отдельным статьям и кейсам.

- Крупные заголовки, заголовки карточек, разделов, FAQ и авторских блоков используют `var(--serif)` с начертанием `500`.
- Основной текст, метаданные, подписи, статусы и списки используют `var(--sans)`.
- В редакционных шаблонах нельзя вводить отдельные шрифтовые переменные или локальные fallback-стеки.
- Размеры заголовков задаются через `clamp()` и проверяются на ширинах 390, 768, 1024 и 1440 px.
- Новая публикация должна проходить `npm run check`; браузерный тест сверяет вычисленные шрифты с токенами `--serif` и `--sans` в Chromium и WebKit.
