# Протокол проверки на реальных устройствах

Этот протокол закрывает ту часть `QA-02`, которую нельзя честно заменить браузерной эмуляцией. Автоматический тест `npm run test:cross-browser` проверяет Chromium, Firefox и WebKit, но чекбокс `QA-02` ставится только после реального прогона ниже.

## Сценарии на каждом мобильном устройстве

- [ ] Первый экран помещает основную CTA без горизонтальной прокрутки.
- [ ] Шапка не перекрывает контент после прокрутки вверх и вниз.
- [ ] Меню открывается, удерживает фокус, закрывается по Escape/кнопке и возвращает исходную позицию страницы.
- [ ] Фиксированные кнопки «Написать сейчас» и «Связаться позже» не перекрыты safe area и имеют удобную область нажатия.
- [ ] Контактный dialog и форма обратной связи открываются выше экранной клавиатуры.
- [ ] После закрытия dialog прокрутка разблокирована, а фокус возвращён на кнопку.
- [ ] Поля имени, контакта, дня, времени и описания не обрезаются при вводе.
- [ ] Увеличение текста в настройках ОС не скрывает CTA и не создаёт горизонтальную прокрутку.
- [ ] Поворот portrait/landscape не оставляет зависший dialog, меню или scroll lock.

## Windows High Contrast

- [ ] Основная и вторичная CTA различимы без фоновых изображений и фирменных цветов.
- [ ] Видимый фокус есть у ссылок, кнопок, полей, checkbox и пунктов меню.
- [ ] Границы полей и dialog различимы.
- [ ] Состояния открытого меню, checkbox и выбранного элемента квиза понятны без одного только цвета.

## Критерий закрытия QA-02

Все строки устройств и все сценарии отмечены, для каждой платформы приложен короткий screen recording или набор снимков, а найденные дефекты либо исправлены отдельным коммитом, либо занесены в таблицу отдельной задачей.
